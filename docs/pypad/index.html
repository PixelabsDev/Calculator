Technical Architecture Commitments

PyPad is engineered with a focus on speed, minimalism, and containment:

  • Zero npm Dependencies: The backend is built exclusively on Node.js built-in standard modules, eliminating third-party supply-chain vulnerabilities.
  • Ephemeral Execution Sandbox: Scripts run inside isolated temporary directories (/tmp/...) that are automatically purged after execution. Python processes run under python3 -I -B -q -u with strict CPU timeouts and ulimit memory caps.
  • Pre-Execution Code Validation: Built-in AST validation (validator.js) prevents system-level escapes, blocking OS commands, subprocess spawning, and outbound network socket connections.
  • Live Interactive Console: Programs stream output in real-time via Server-Sent Events (SSE) and accept mid-run interactive standard input without artificial buffering.
  • Isolated Workspaces: Persistent files are restricted to a dedicated user space protected by strict directory traversal guards (safePath) and storage quotas.
