Privacy Policy for Pixelabs Tools

Effective Date: November 1, 2026  |  Service: Pixelabs Tools (tools.pixelabs.in)  |  Publisher: Pixelabs Digital Services / Vishal Kumar

Browser-First Privacy: Pixelabs Tools operates predominantly client-side. When you compress an image, merge a PDF, calculate a hash, or format code, your files and text never leave your computer or smartphone.

1. Architecture: Local Browser Processing

Pixelabs Tools utilizes modern web technologies including WebAssembly (Wasm), Web Workers, and the HTML5 Canvas / File APIs. All file operations, parsing, formatting, and transformations are executed locally inside your web browser's isolated sandbox memory.

  • No File Uploads: Your documents, spreadsheets, photographs, PDF files, and cryptographic keys are NOT uploaded to our servers.
  • No File Storing: We do not operate remote databases or cloud buckets storing user files processed via client-side tools.
  • Offline Capability: Once the web page assets are cached by your browser, many utilities continue working even without an active internet connection.

2. Optional Ephemeral Cloud Mode

Certain high-intensity operations (such as advanced OCR or large-scale document vectorization) may offer an optional Cloud Processing Mode. If and only when you explicitly opt into Cloud Mode:

  • Files are transferred securely using TLS 1.3 encryption directly to our processing cluster.
  • The data is held strictly in ephemeral volatile system memory (RAM) while processing occurs.
  • The processed output is streamed back to your browser, and the memory buffer is immediately wiped and freed.
  • Zero Disk Persistence: Your files are never written to physical hard drives, long-term databases, or shared cloud storage.

3. Cookies, Analytics & Tracking

Pixelabs Tools does not use invasive surveillance or third-party marketing tools:

  • Zero Tracking Cookies: We do not drop tracking cookies, advertising beacons, or cross-site tracking tags.
  • No Account Mandatory: You do not need to register an account, provide an email address, or log in to utilize tools.pixelabs.in.
  • Local Settings Persistence: UI preferences (such as dark mode or tool configuration flags) are saved in your browser's local localStorage or IndexedDB, fully controlled by you.

4. Infrastructure & Server Access Logs

When you request static web files (HTML, CSS, JavaScript, WebAssembly binaries), standard non-identifying HTTP request metadata is recorded by our edge delivery provider (Cloudflare) to ensure security, prevent Distributed Denial of Service (DDoS) attacks, and optimize content caching:

  • Anonymized IP address, timestamp, requested URL, user-agent string, and HTTP status code.
  • These edge network logs do not contain any content from the files you process and are automatically discarded according to standard Cloudflare security retention schedules.

5. Security of Local Data

Because files are processed within your web browser, their privacy is secured by your browser's Same-Origin Policy and sandboxing protections. To preserve complete privacy, ensure that your web browser and operating system remain updated with current security patches.
