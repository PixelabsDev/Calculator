Privacy Policy for Pixelabs Tools

Effective Date: November 1, 2026  |  Service: Pixelabs Tools (tools.pixelabs.in)  |  Publisher: Pixelabs Digital Services

Browser-First Privacy: Pixelabs Tools operates client-side. When you compress images, manipulate PDFs, format code, or calculate cryptographic hashes, your files and inputs remain in your browser and are never uploaded to our servers.

1. Local Browser Processing (WebAssembly)

Pixelabs Tools is built with modern browser technologies including WebAssembly (Wasm), Web Workers, and HTML5 File APIs. File transformations occur locally inside your browser's sandboxed process.

  • No File Uploads: Documents, images, spreadsheets, and data you open are not transmitted to remote cloud storage.
  • No Remote Databases: We do not operate databases or buckets storing user files processed via client-side utilities.
  • Offline Resilience: Once cached by your browser, utilities can be utilized without an active internet connection.

2. Optional Ephemeral Cloud Mode

Where high-intensity operations (such as advanced OCR or heavy machine-learning conversions) offer an optional Cloud Processing Mode:

  • Transfers are encrypted via HTTPS/TLS 1.3 directly to our computational cluster.
  • Data is processed strictly in volatile system memory (RAM).
  • Processed results are streamed back to your client, and memory buffers are immediately wiped.
  • Files are never written to physical disk storage or persistent drives.

3. Cookies & Tracking

  • No Tracking Cookies: We do not utilize tracking cookies, advertising pixels, or analytics trackers.
  • No Account Required: No registration, email address, or login credentials are required to use tools.pixelabs.in.
  • Local Preferences: Tool configuration states or dark mode choices are stored locally in your browser's localStorage.

4. Infrastructure Logs

Standard non-identifying HTTP request logs are recorded by our edge delivery provider (Cloudflare) for DDoS mitigation, caching, and security enforcement. These logs contain standard metadata (IP address, user-agent, requested file) and do not contain file contents.
