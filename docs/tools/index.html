Privacy Policy

Complete disclosure of our client-side WebAssembly architecture. Files process directly in your browser with zero server uploads, no accounts, and no tracking cookies.

Terms of Service

Acceptable use policy, liability limitations, and intellectual property terms confirming you retain 100% ownership of processed files.

Technical Architecture Commitments

  • In-Browser Execution: Files and documents are processed locally inside your browser's sandboxed memory using compiled WebAssembly (Wasm) and HTML5 APIs. Files never leave your device.
  • Optional Cloud Mode: If a tool offers an optional cloud computation mode, files are processed strictly in ephemeral system memory (RAM) and destroyed immediately upon output streaming, with zero disk storage.
  • No Account Required: Pixelabs Tools requires no registration, login credentials, or tracking cookies to operate.
