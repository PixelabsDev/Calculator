Our Core Privacy Commitments

Across all software developed and distributed by Pixelabs, we adhere to strict architectural privacy principles:

  • Local-First Computation: Operations run directly on your device CPU/GPU without remote server dependencies whenever technologically possible.
  • Zero Stealth Telemetry: We do not integrate advertising trackers, behavioral fingerprinting scripts, or third-party data broker SDKs.
  • Explicit User Consent: Any voluntary diagnostic or error reporting requires affirmative user initiation with complete disclosure.
