Our Core Privacy Commitments

Across all software distributed by Pixelabs, we adhere to strict architectural privacy principles:

  • Local-First Computation: Whenever technologically possible, operations run directly on your device CPU/GPU without remote server dependencies.
  • Zero Stealth Telemetry: We do not integrate advertising trackers, behavioral fingerprinting scripts, or third-party data broker SDKs.
  • Explicit User Consent: Any voluntary diagnostic or error reporting requires affirmative user initiation with clear disclosure.
