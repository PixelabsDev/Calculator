Our Foundational Privacy Principles

At Pixelabs, privacy is not an afterthought or a marketing claim—it is a core engineering constraint applied across every application and service we release:

1. Local-First Processing: Whenever mathematically or technically possible, computations and file manipulations are performed directly on your local device CPU/GPU. We avoid server dependencies for offline utilities.

2. Zero Stealth Telemetry: We do not integrate hidden analytics SDKs, advertising trackers, or fingerprinting scripts. We reject predatory data broker networks.

3. Explicit Voluntary Consent: If an application offers voluntary feedback or cloud assistance, it requires deliberate, affirmative opt-in consent with clear diagnostic disclosures.
