Technical Architecture Commitments

  • 100% Offline Core: Mathematical evaluation, trigonometric functions, and expression parsing execute locally on your device CPU. No internet permissions are required for core calculations.
  • Local Data Storage: Calculation history is stored in a private on-device Android Room SQLite database. Theme and angular preferences are stored in Android Jetpack DataStore.
  • Voluntary Feedback: In-app error reporting requires explicit user initiation. Data is held for 90 days solely for debugging and then purged.
