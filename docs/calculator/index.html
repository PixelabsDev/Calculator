Architecture & Data Safety Commitments

Pixelabs Calculator has been engineered from the ground up according to strict zero-trust data safety principles:

100% Offline Core: All mathematical evaluation, scientific functions (trigonometric, logarithmic, powers, factorials), and expression formatting are performed synchronously in-memory by our Kotlin math engine on the device's CPU. The core calculation features require no network access.

Local-Only Storage: Your calculation history is stored locally in an encrypted Android Room SQLite database on your device. User UI preferences (Angle Mode DEG/RAD, Theme Light/Dark/System) are persisted strictly using Jetpack DataStore. No cloud sync is performed unless explicitly initiated by the user.

Voluntary Diagnostic Feedback: Users may voluntarily submit diagnostic logs or error reports to assist development. Submissions require explicit, affirmative user confirmation, contain no personal identifying information, and are purged after 90 days.
